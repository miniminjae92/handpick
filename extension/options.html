Element to Markdown

Click the toolbar icon on any page, pick an action, then click the element you want to capture. These settings shape what you get.

Output format

  • Standard Markdown — the safe default. Works in any Markdown app.
  • Obsidian — same output, plus supported alert boxes on webpages become Obsidian callouts.

Source frontmatter

Frontmatter is a small header at the top of a note that records where and when you captured it: 

---
title: "How to brew pour-over coffee"
source: "https://example.com/pour-over-guide"
created: 2026-07-23T14:05:00.000Z
---

The default keeps copies clean for pasting into existing notes. Plain-text copies never include frontmatter.

Save to Obsidian

The Save to Obsidian action creates the note directly in your vault. It needs the Obsidian desktop app installed.

Type your vault's name exactly as Obsidian shows it, including spaces. You can see it in Obsidian's window title, or in the vault switcher at the bottom-left corner of Obsidian.

Where new notes land — for example Clippings or Inbox/Web. Leave it empty to save at the top level of the vault.

The first save asks the browser for permission to open Obsidian — allow it once and it won't ask again.

Keyboard shortcuts

  • Copy Markdown — default Alt/Option + Shift + C
  • Save Markdown — default Alt/Option + Shift + S
  • Copy plain text — no default; assign one below if you use it.
