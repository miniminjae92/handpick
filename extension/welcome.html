Element to Markdown

Capture your first element

  1. Open any normal webpage (browser pages like this one are restricted).
  2. Click the Element to Markdown toolbar icon and pick an action — or right-click the page, or use a keyboard shortcut.
  3. Click the element you want. Use ↑ / ↓ to widen or narrow the selection, Esc to cancel.

The toast in the corner offers the same capture as plain text or HTML, and a reviewable bug report draft if the conversion looks wrong.

Default shortcuts

  • Alt/Option + Shift + C — copy as Markdown
  • Alt/Option + Shift + S — save as .md
  • Copy plain text has no default — assign one if you use it.

Make it yours

Choose Standard or Obsidian output, control source frontmatter, and set an Obsidian vault to save notes directly into it.
