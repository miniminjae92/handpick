웹에서 좋은 정보를 노트로 옮기는 체크리스트

복사한 내용이 깨지지 않게 보관하려면, 내용뿐 아니라 구조도 함께 가져와야 합니다.

핵심: 제목, 목록, 표, 코드 블록이 유지되면 나중에 다시 읽고 재사용하기가 훨씬 쉬워집니다.

1. 먼저 가져올 범위를 고릅니다

페이지 전체보다 지금 필요한 부분만 선택하는 편이 더 좋습니다.

  • 답변 전체가 아니라 필요한 섹션만
  • 설명과 예제가 함께 있는 블록
  • 표나 코드가 포함된 덩어리

2. 기록에 남길 때 확인할 것

  1. 제목 계층이 유지되는가
  2. 목록이 한 문단으로 뭉개지지 않는가
  3. 코드 블록과 표가 다시 읽기 좋은가

좋은 기록은 다시 찾았을 때 바로 이해되는 기록입니다.

3. 간단한 비교

형식 장점 주의점
Plain text 가볍고 어디서나 붙여넣기 쉬움 구조가 일부 사라짐
Markdown 구조와 가독성을 함께 보존 변환 품질이 중요함

4. 코드 예시

function saveNote(title, body) {
  return {
    title,
    body,
    savedAt: new Date().toISOString()
  };
}

5. 작업 체크리스트

  • [x] 필요한 영역을 고른다
  • [x] Markdown으로 복사한다
  • [ ] 노트에 붙여넣고 최종 확인한다

이 문서는 데모 촬영용 샘플입니다. 링크 예시는 example.com을 사용합니다.
