# Privacy Policy

## Summary

Handpick processes only the page element that the user explicitly selects.

## What the extension handles

When the user invokes the extension and clicks an element, the extension reads that selected element's HTML in order to:

- convert it to Markdown,
- copy it as plain text,
- copy its HTML,
- save it as a `.md` file, or
- prepare a bug report draft when the user chooses `Report issue`.

## What the extension does not do

- It does not automatically upload selected page content.
- It does not collect browsing history.
- It does not track users.
- It does not use analytics or advertising SDKs.
- It does not create accounts or require login.

## Bug reports

If the user chooses `Report issue`, the extension prepares a draft containing the selected HTML and conversion outputs so the user can review, edit, download, or manually submit them.

The extension does not send that content anywhere without an explicit user action.

## Data retention

Bug report draft data is kept only temporarily for the current browser session so the report page can be opened. It is not intended for long-term storage.

## Contact

For questions about this policy, contact the project maintainer through the repository issue tracker.
