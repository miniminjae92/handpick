# Chrome Web Store listing copy

## Name

Element to Markdown

## Short description

Select any page element and copy or save it as clean Markdown.

## Detailed description

Element to Markdown lets you select any element on a webpage and quickly copy or save it as clean Markdown.

It is especially useful when moving AI-generated answers, technical docs, blog posts, tables, or code-heavy web content into your personal notes. Compared with ordinary copy and paste, it aims to preserve structure such as headings, lists, tables, blockquotes, and code blocks more reliably.

### Key features

- Option + Shift + C: copy the selected element as Markdown
- Option + Shift + S: save the selected element as a `.md` file
- Configure shortcuts for copy, save, and plain text actions in Chrome's shortcut settings
- Copy plain text or HTML from the same selection
- Choose Standard Markdown or Obsidian output for supported callouts
- Create a reviewable bug report draft when conversion fails
- Local, browser-side processing by default

### Useful for

- Saving AI answers into Obsidian, Notion, or Markdown notes
- Capturing only the exact section you want from a webpage
- Preserving tables, checklists, and code blocks more cleanly

### Privacy

Element to Markdown only processes the element you explicitly select. Selected HTML is not uploaded automatically, and bug reports are only shared when you review and submit them yourself.

## Korean detailed description

Element to Markdown은 웹페이지에서 내가 직접 고른 요소를 Markdown으로 빠르게 복사하거나 저장하는 확장프로그램입니다.

AI가 생성한 답변, 기술 문서, 블로그 글, 표와 코드가 포함된 웹 콘텐츠를 개인 노트에 옮길 때 유용합니다. 일반 복사보다 제목, 목록, 표, 코드 블록 같은 구조를 더 잘 보존하도록 정리합니다.

### 주요 기능

- Option + Shift + C: 선택한 요소를 Markdown으로 복사
- Option + Shift + S: 선택한 요소를 `.md` 파일로 저장
- Chrome 단축키 설정에서 복사, 저장, plain text 액션 단축키를 직접 지정
- 같은 선택 결과에서 plain text 또는 HTML도 복사
- 지원되는 callout은 Standard Markdown 또는 Obsidian 출력으로 선택
- 변환이 이상하면 검토 가능한 버그 리포트 초안 생성
- 기본적으로 브라우저 안에서만 처리

### 이런 때 유용합니다

- AI 답변을 Obsidian, Notion, Markdown 노트로 옮길 때
- 웹 문서의 특정 섹션만 기록하고 싶을 때
- 표, 체크리스트, 코드 블록이 포함된 내용을 덜 깨지게 저장하고 싶을 때

### 개인정보

Element to Markdown은 사용자가 직접 선택한 요소만 처리합니다. 선택한 HTML은 자동으로 외부 전송되지 않으며, 버그 리포트도 사용자가 직접 확인하고 제출할 때만 외부로 전달됩니다.
