# Demo assets plan

## Main video

Recommended length: about 30 seconds.

### Suggested flow

1. Show a GPT answer with rich structure.
2. Press `Option + Shift + C`.
3. Select the answer block manually.
4. Paste the copied Markdown into a notes app.
5. Show preserved headings, lists, table, checklist, and code block.
6. Open `sample.html`.
7. Press `Option + Shift + S`.
8. Save the selected article as `.md`.
9. Briefly show toast actions:
   - `Copy plain text`
   - `Copy HTML`
10. If useful, briefly show that output format can be set to:
    - `Standard Markdown`
    - `Obsidian`
11. End on the product name.
