# Element to Markdown — 제품 결정 문서 v1

## 1. 제품 정의

웹페이지에서 내가 직접 고른 요소를, 별도 페이지 이동 없이 Markdown으로 즉시 복사하거나 저장하는 Chrome 확장프로그램.

가끔 필요할 때는 같은 선택 결과를 plain text로도 복사할 수 있다.

이 도구의 핵심은 자동 추출이 아니라, **내가 직접 고른 영역을 빠르고 덜 깨지게 가져오는 것**이다.

## 2. 해결하려는 문제

현재 사용 흐름:

1. 개발자 도구 열기
2. 요소 선택 모드 실행
3. 원하는 영역 클릭
4. `Copy element`
5. 변환 사이트로 이동
6. 붙여넣기
7. Markdown 복사 또는 파일 저장

이 흐름은 결과는 좋지만, 중간 단계가 많다.

확장프로그램 v1은 이를 다음처럼 줄인다.

- 복사: `Option + Shift + C` → 요소 클릭
- 저장: `Option + Shift + S` → 요소 클릭

## 3. 이름

### Element to Markdown

선택 이유:

- 현재 핵심 가치를 가장 정확하게 드러낸다.
- `Element to`라는 구조가 수동 선택 기반의 성격과 잘 맞는다.
- plain text가 보조 기능으로 추가되어도, 주력 포맷이 Markdown이라는 점이 여전히 분명하다.

## 4. 핵심 사용자와 사용 맥락

1차 사용자는 본인이다.

주요 사용 맥락:

- AI가 생성한 답변을 개인 기록으로 옮길 때
- 웹상의 좋은 정보 일부를 내 노트에 저장할 때
- 일반 복사/붙여넣기에서 제목, 리스트, 표, 코드 블록 등이 깨지는 불편을 줄이고 싶을 때

## 5. 반드시 지킬 제품 원칙

### 5.1 수동 선택을 기본으로 한다

자동 본문 추출보다, 사용자가 마우스로 직접 원하는 요소를 고르는 방식을 유지한다.

### 5.2 자주 하는 일은 가장 짧게

- 복사: `Option + Shift + C`
- 저장: `Option + Shift + S`

선택 후 추가 확인 없이 바로 실행된다.

### 5.3 변환 대상은 선택한 HTML 조각 그 자체

페이지 제목, URL, 저장 시각 등 메타데이터를 추가하지 않는다.

### 5.4 지금 웹 버전의 장점을 계승한다

현재 웹 도구가 잘 처리하는:

- 제목
- 문단
- 리스트
- 체크리스트
- 표
- 코드 블록
- 인용문
- 링크
- 이미지

보존 로직을 확장프로그램에서도 최대한 재사용한다.

### 5.5 서버 없이 동작한다

선택한 내용은 브라우저 안에서만 처리한다.

외부 전송, 로그인, 클라우드 저장은 v1에 포함하지 않는다.

## 6. 단축키

### 기본 단축키

- `Option + Shift + C`: 선택한 요소를 Markdown으로 복사
- `Option + Shift + S`: 선택한 요소를 Markdown 파일로 저장

선택 이유:

- `C = Copy`, `S = Save`라 기억하기 쉽다.
- 기존 `Command + Shift + C`와 비슷한 결을 유지하면서 충돌을 피한다.
- 가장 자주 쓰는 두 행동에 직접 진입할 수 있다.

## 7. v1 사용자 흐름

### 7.1 복사 흐름

1. 사용자가 `Option + Shift + C`를 누른다.
2. 요소 선택 모드가 시작된다.
3. 마우스를 올린 요소가 하이라이트된다.
4. 사용자가 원하는 요소를 클릭한다.
5. 해당 요소가 Markdown으로 변환되어 즉시 클립보드에 복사된다.
6. 토스트가 뜬다.
   - `Markdown copied`
   - `Save .md`
   - `Copy plain text`

### 7.2 저장 흐름

1. 사용자가 `Option + Shift + S`를 누른다.
2. 요소 선택 모드가 시작된다.
3. 원하는 요소를 클릭한다.
4. 해당 요소가 Markdown으로 변환되어 `.md` 파일로 저장된다.
5. 토스트가 뜬다.
   - `Saved as .md`
   - `Copy Markdown`
   - `Copy plain text`

## 8. 출력 형식

### 8.1 Markdown

현재 웹 버전의 변환 방향을 그대로 따른다.

보존 대상:

- heading
- paragraph
- list / nested list
- checklist
- table
- code / code block
- blockquote
- link
- image

### 8.2 Plain text

plain text는 **Markdown 문법은 제거하되 읽기 쉬운 구조는 유지하는 텍스트**로 정의한다.

원칙:

- 제목 기호 제거
- 링크는 라벨 텍스트만 유지
- 리스트는 줄 단위 구조 유지
- 코드 블록은 코드 내용만 유지
- 문단 구분 유지
- 표는 읽을 수 있는 단순 텍스트 구조로 변환

## 9. 파일 저장 규칙

현재 웹 버전과 동일한 규칙을 사용한다.

1. 첫 번째 Markdown heading이 있으면 그 텍스트를 파일명으로 사용
2. 없으면 `converted.md`
3. 파일명에서 OS에 부적합한 문자는 제거
4. 공백은 `-`로 치환
5. 길이는 적절히 제한

## 10. UI 결정

### 선택 모드

- hover 시 요소 하이라이트
- 클릭 시 확정
- `Esc`로 취소

### 토스트

복사/저장 완료 직후 짧게 표시한다.

#### 복사 후

- `Markdown copied`
- `Save .md`
- `Copy plain text`

#### 저장 후

- `Saved as .md`
- `Copy Markdown`
- `Copy plain text`

### v1에서 넣지 않는 UI

- 매번 뜨는 미리보기 모달
- 복잡한 설정 화면

## 12. 성공 기준

v1이 성공한 것으로 볼 기준:

- 기존의 `F12 → 요소 선택 → Copy element → 변환 사이트 이동 → 붙여넣기` 흐름이 `단축키 → 클릭`으로 줄어든다.
- 현재 웹 버전과 비슷한 수준으로 Markdown 구조가 보존된다.
- 복사와 저장이 각각 빠르게 실행된다.
- plain text도 같은 선택 결과에서 바로 얻을 수 있다.
- “내가 직접 고른다”는 기존 장점이 사라지지 않는다.
